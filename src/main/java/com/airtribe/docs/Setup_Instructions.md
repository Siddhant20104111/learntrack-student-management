# Setup Instructions – LearnTrack Project

## 1. JDK Version Used

JDK Version: 22
(You can check using command: `java -version`)

---

## 2. Installing Java (JDK)

1. Download JDK from official Oracle website or OpenJDK.
2. Install the JDK.
3. Set environment variables:

    * JAVA_HOME
    * Add JDK bin folder to PATH

---

## 3. Verify Installation

Run the following commands in terminal:

```
java -version
javac -version
```

If installed correctly, it will display the Java version.

---

## 4. Hello World Program

### Code:

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, LearnTrack!");
    }
}
```

---

## 5. Compile and Run

### Step 1: Compile

```
javac HelloWorld.java
```

### Step 2: Run

```
java HelloWorld
```

---

## 6. Output

```
Hello, LearnTrack!
```
